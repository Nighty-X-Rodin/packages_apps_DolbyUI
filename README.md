# Dolby Atmos UI (LunarisDolby)

## How to use

1. **Clone this repository** into `packages/apps/DolbyUI` in your ROM source:
   ```bash
   git clone https://github.com/Nighty-X-Rodin/packages_apps_DolbyUI.git packages/apps/DolbyUI
   ```

2. **Include in `device.mk`**:
   ```makefile
   # Dolby
   PRODUCT_PACKAGES += \
       LunarisDolby
   ```
